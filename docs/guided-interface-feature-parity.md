# 简洁界面功能还原清单

目标：用户完成任何日常或高级 Git 操作时，都不需要退回原版界面。

> 2026-09-03 已完成全菜单/源码覆盖审计和分阶段接入。完整证据、原版清单和逐项对比见 `docs/original-vs-guided-functional-audit.md`。

## 0. 独立应用前提

- [x] 可见产品名不再带“引导版”；独立安装包应用名：`Git Agent Clear`，窗口显示 `Git Agent`。
- [x] 独立 Bundle ID：`io.github.adoin.git-agent-clear`。
- [x] 独立主程序、配置目录、日志目录和钥匙串服务名。
- [x] 原版和简洁版同时启动并独立打开不同测试仓库。
- [x] 禁用指向原版安装包的自动更新，避免覆盖或身份回退。

状态说明：

- `[x]` 已在简洁界面提供入口，并连接原项目真实功能。
- `[~]` 已有基础入口，但操作能力或引导尚未完整还原。
- `[ ]` 尚未在简洁界面提供完整入口。
- 每一项只有在完成代码接入、忙碌状态保护、成功/失败反馈和回归验证后才能标记为 `[x]`。

## 1. 工作目录与仓库

- [x] 打开电脑里已有的 Git 项目。
- [x] 选择普通文件夹并创建新的本地 Git 项目。
- [x] 输入远程地址和保存位置，克隆并自动打开项目。
- [x] 查看并切换已经打开或最近使用的工作目录。
- [x] 关闭、重命名和拖动排序已打开的项目标签。
- [x] 添加、移除和切换“项目文件夹分组”。

## 2. 保存改动

- [x] 查看已暂存和未暂存文件。
- [x] 单个文件暂存、取消暂存。
- [x] 填写说明并创建本地提交。
- [x] 查看文件差异。
- [x] 全部暂存、全部取消暂存。
- [x] 打开文件、在访达中显示文件。
- [x] 忽略文件、停止跟踪、删除文件。
- [x] 丢弃单个或全部改动，并完整说明恢复方式。
- [x] 提交选项：立即推送、修订上次提交、跳过钩子、GPG 签名、历史说明。

## 3. 与远程同步

- [x] 获取远程状态（Fetch）。
- [x] 下载并合入更新（Pull）。
- [x] 上传本地提交（Push）。
- [x] 选择远程、目标分支和推送策略。
- [x] 查看远程网页、创建 Pull Request。
- [x] 新增、修改、删除和测试远程地址。
- [x] 认证失败、无上游、分叉和冲突场景的完整引导。

## 4. 历史版本

- [x] 浏览提交历史和基本提交详情。
- [x] 查看提交所改文件与差异。
- [x] 搜索提交。
- [x] 切换日期/拓扑排序和全部/当前分支范围。
- [x] 比较提交、分支和工作区。
- [x] 检出、回退、反向提交、拣选和归档提交。
- [x] 从历史提交创建分支或标签。

## 5. 工作线（分支）

- [x] 查看本地分支。
- [x] 创建并切换到新分支。
- [x] 切换本地分支。
- [x] 查看远程分支。
- [x] 检出远程分支并设置跟踪关系。
- [x] 分支拉取、推送、合并、变基和比较。
- [x] 重命名、删除本地分支和删除远程分支。

## 6. 临时收起改动（Stash）

- [x] 创建临时收起记录。
- [x] 恢复但保留临时记录（Apply）。
- [x] 恢复并删除临时记录（Pop）。
- [x] 删除临时记录（Drop）。
- [x] 已暂存、未跟踪、已忽略文件等收起范围选项。

## 7. 冲突与历史整理

- [x] 打开三方冲突解决工具。
- [x] 在简洁界面完成冲突文件选择、逐块解释、应用和中止流程。
- [x] 打开交互式变基工具。
- [x] 在简洁界面解释并覆盖排序、压缩、修订、删除、继续和中止变基。
- [x] 合并分支的目标选择、影响说明、冲突处理和结果验证。

## 8. 标签、补丁与高级仓库能力

- [x] 创建标签。
- [x] 检出、推送和删除标签。
- [x] 打开创建补丁入口。
- [x] 创建、保存、导入和应用补丁的完整引导。
- [x] Git LFS 初始化入口。
- [x] Git LFS 跟踪、取消跟踪、拉取、获取、检出和清理。
- [x] Git Flow 初始化/操作入口。
- [x] Git Flow 的 Feature、Release、Hotfix 完整流程。
- [x] 添加子模块入口。
- [x] 子模块和子树的添加/链接、递归选项与错误处理。
- [x] 仓库性能测试。

## 9. 工具、设置与桌面能力

- [x] 打开仓库设置和全局设置，并可直接定位具体设置页。
- [x] 仓库忽略规则编辑器，含逐行解释、异步保存、失败恢复和仓库刷新。
- [x] SSH、提交身份、托管账号、AI、语言、主题、字体和字号设置。
- [x] 打开终端、访达、外部差异工具和自定义命令。
- [x] 刷新、键盘快捷键、项目标签导航和窗口状态恢复。
- [x] 新手说明开关状态持久化。
- [x] 原版没有独立“代理设置”；已从误记的还原范围中移除，不提供无后端的假入口。
- [x] 更新检查入口保留；独立 Release 源未建立前明确显示不可更新，绝不下载原版安装包造成覆盖。

## 实施顺序

1. 工作目录与仓库闭环。
2. 保存改动的文件操作与提交选项。
3. 远程同步的完整参数与异常引导。
4. 历史搜索、比较和恢复操作。
5. 分支与远程分支完整管理。
6. Stash 完整管理。
7. 冲突、合并与变基。
8. 标签、补丁、LFS、Git Flow、子模块和子树。
9. 设置、外部工具、快捷键和最终全量验收。
