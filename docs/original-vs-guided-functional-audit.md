# Git Agent 原版与简洁版功能对照及验收记录

审计日期：2026-09-03

原版：`/Applications/Git Agent.app`

简洁版：`/Users/shuke/Desktop/git中台/dist/Git Agent Clear.app`（窗口内显示 `Git Agent`）

## 最终结论

1. 原版与简洁版是两个可共存的 macOS 应用。Bundle ID、可执行文件、配置、日志、钥匙串和安装包名称均隔离。
2. 简洁版不是静态套壳。页面按钮连接项目原有的 Git 命令、异步任务和设置存储；日常流程已在隔离仓库实际执行。
3. 用户不需要回到原版主界面。原版功能已从“高级工具”或“设置与电脑工具”进入；部分复杂功能继续复用项目原有的真实对话框/编辑器，而不是重新造一份无后端的演示页面。
4. 没有“只能看、不能用”的占位功能。按钮在缺少仓库、远程、冲突或外部账号等前置条件时会禁用或解释原因。
5. 唯一有意不同的是自动更新：简洁版尚无独立 Release 下载源，所以“检查更新”会明确说明不可更新，绝不下载原版安装包覆盖简洁版。

## 验收口径

- `✅ 实操`：在应用里点击，并核对真实仓库或持久化状态发生变化。
- `✅ 回归`：真实调用路径与对应后端由自动化测试覆盖。
- `✅ 界面`：实际打开页面/对话框，核对入口、说明、禁用状态和结果反馈。
- `环境依赖`：功能已接入，但最终外部结果还取决于用户的 Git 托管账号、SSH、API Key 或远程仓库权限。

## 一、原版完整功能清单

### 1. 项目、窗口与工作空间

- 打开已有仓库、创建本地仓库、克隆远程仓库。
- 多仓库标签：打开、切换、关闭、改名、拖动排序、溢出列表、上一个/下一个。
- 工作空间目录：添加、移除、扫描、分组、搜索和快速打开。
- 刷新当前仓库、恢复窗口大小和上次打开项目。

### 2. 工作区、文件与提交

- 已暂存、未暂存、未跟踪、冲突和重命名状态。
- 单个/批量/全部暂存与取消暂存；列表/树展示和多选。
- 文件差异、差异块、打开文件、访达定位、复制路径、终端和外部 Diff。
- 原版可查看提交历史与 Blame，但不提供工作区文件的本机创建/修改时间和 Git 历次保存记录统一追溯入口。
- 忽略、停止跟踪、删除、丢弃单个或全部改动。
- 普通提交、立即推送、修订上次提交、跳过钩子、GPG 签名和提交说明历史。
- 提交身份、撤销/重做本地提交、变基期间继续/跳过/中止。

### 3. 远程同步与托管平台

- Fetch：选择远程、全部远程、Prune、标签和强制更新标签。
- Pull：选择远程/远程分支/本地分支，合并或 Rebase，标签和合并策略。
- Push：多分支、远程目标、设置跟踪、标签和 `--force-with-lease`。
- 无上游、非快进、分叉、认证和冲突的恢复流程。
- 远程地址新增/修改/删除、打开远程网页、创建 Pull Request、托管账号匹配。

### 4. 历史版本与搜索

- 提交图、引用、当前/全部分支、日期/拓扑排序、远程引用。
- 搜索提交、查看提交文件和差异、与工作区或其他引用比较。
- 检出、创建分支/标签、Cherry-pick、Revert、Reset、归档和打开远程提交。
- 从历史开始交互式变基。

### 5. 分支、标签与贮藏

- 本地/远程分支树、新建、检出、跟踪、重命名、删除和远程删除。
- 分支 Fetch/Pull/Push、设置上游、合并、变基、比较和 Pull Request。
- 标签创建、检出、推送和删除。
- Stash Create/Apply/Pop/Drop；已暂存、未跟踪、已忽略和保留暂存范围。

### 6. 合并、冲突与历史整理

- 合并目标、立即提交、说明、强制合并提交、Rebase 和重命名检测。
- 三方冲突工具：本地/远程取舍、手工编辑、撤销/重做、应用结果和 AI 建议。
- 交互式变基：Pick、Reword、Edit、Squash、Fixup、Drop、排序、作者、Autosquash、继续/跳过/中止。

### 7. 高级仓库能力

- 补丁：从工作区或提交创建、合并/分文件保存、导入和三方应用。
- Git LFS：初始化、跟踪/取消、Pull、Fetch、Checkout、Prune。
- 子模块、子树、Git Flow Feature/Release/Hotfix、Git Archive 和性能基准测试。

### 8. 设置与桌面工具

- 浅色/深色/系统主题、主题色、背景图案、文字对比、字重、界面字体、代码字体、缩放和中英文。
- SSH 客户端、密钥、SSH Agent；提交身份和托管平台账号。
- 可选 AI 模型、API 地址、API Key、模型 ID、连通测试和安全存储。
- 自定义 Git 操作；仓库远程、`.gitignore`、身份、提交链接和刷新规则。
- 访达、终端、教程、快捷键、关于、更新检查和日志诊断。

原版没有独立的 HTTP/HTTPS 代理设置页面；Git 网络代理继续继承系统或 Git 自身配置。

## 四、实际操作记录

- 原版与简洁版进程同时存在，Bundle ID 不同。
- 简洁版完成已有仓库打开、本地仓库创建和本机远程克隆。
- 简洁版完成单文件暂存/取消、全部暂存、填写说明和真实提交。
- 简洁版对本机裸远程完成 Fetch、Pull、Push，并核对待下载/待上传数量归零。
- 简洁版完成分支创建/切换和 Stash Create/Apply。
- 历史页显示真实提交、哈希、作者、时间和引用。
- 时间追溯实测未提交 ZIP 可显示本机创建/修改时间和“尚未进入 Git”；已提交后再修改的文件可显示 Git 最后保存时间、提交人、提交编号和历次记录。验证用隔离仓库的临时修改已还原。
- 修复简洁页头占用空间后历史列表高度上下限倒置导致的闪退；在 768 像素高窗口内连续切换并打开历史页 3 次，页面与日志均正常。
- 设置页实际切换到深色再恢复浅色；重启后仓库、主题和新手说明开关均恢复。
- 关闭新手说明后仍为简洁界面，不会出现原版主界面。
- “忽略规则”实际打开当前仓库 `.gitignore` 编辑器。
- “检查更新”在无独立源时显示明确失败说明；“关于”显示 `Git Agent 1.3.14`。
- 多次重新启动简洁版，未再次出现连续四次钥匙串授权弹窗。
